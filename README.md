# Phone and Gadget Store

## Project Overview
This project is a full-stack web application designed for an online phone and gadget store. It features a user-friendly interface for customers to browse products, manage their accounts, and place orders. The application also includes an admin panel for managing products, orders, and users.

## File Structure
- **index.html**: Main entry point for the user interface.
- **style.css**: Styles for the main user interface.
- **script.js**: JavaScript logic for the main user interface.
- **products.json**: Stores product details.
- **orders.json**: Tracks user orders.
- **users.json**: Contains user authentication details.
- **customerMessages.json**: Stores customer inquiries and feedback.
- **updates.json**: Contains notifications for users.
- **server.js**: Backend logic using Node.js and Express.
- **package.json**: Configuration file for npm.
- **admin-panel/**: Contains files for the admin interface.

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the required dependencies by running `npm install`.
4. Start the server using `node server.js`.
5. Open `index.html` in your browser to view the application.

## Features
- User authentication and registration.
- Product listing with detailed information.
- Shopping cart functionality.
- Order tracking for users.
- Admin panel for managing products, orders, and users.

## Usage
- Users can browse products, add them to their cart, and place orders.
- Admins can log in to manage the store's inventory and view orders.

## Technologies Used
- HTML, CSS, JavaScript for the frontend.
- Node.js and Express for the backend.
- JSON files for data storage.
